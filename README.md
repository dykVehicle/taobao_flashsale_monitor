# 淘宝闪购商品监控工具

📊 自动监控淘宝闪购商家版的商品状态，统计已下架和已售罄的产品，并通过企业微信机器人发送到门店群。

## ✨ 功能特性

- 🔍 **商品抓取**: 自动获取淘宝闪购商家后台的商品列表
- 📈 **状态统计**: 统计在售、已下架、已售罄、缺货、暂停售卖的商品数量
- 📑 **Excel导出**: 将商品数据导出为Excel报表，包含分类统计
- 🤖 **企业微信通知**: 通过企业微信机器人将报告发送到门店群
- ⏰ **定时任务**: 支持定时检查和每日报告

## 📦 安装

```bash
# 进入工具目录
cd taobao_flashsale_monitor

# 安装依赖
pip install -r requirements.txt
```

## ⚙️ 配置

### 1. 获取Cookie

1. 在浏览器中打开 [淘宝闪购商家后台](https://napos-goods-pc.faas.ele.me/single/goods-manage)
2. 按 `F12` 打开开发者工具
3. 切换到 `Network`(网络) 标签
4. 刷新页面，点击任意API请求
5. 在 `Headers` 中找到 `Cookie` 字段，复制其值

### 2. 配置门店信息

编辑 `config.py` 文件：

```python
# 门店配置
STORES = [
    {
        "name": "门店名称",
        "shop_id": "1303549223",  # 从URL获取
        "webhook": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY"
    },
    # 添加更多门店...
]

# Cookie配置
API_CONFIG = {
    "cookie": "粘贴你的Cookie到这里",
    ...
}
```

### 3. 获取企业微信Webhook

1. 在企业微信中创建一个群
2. 点击群设置 → 群机器人 → 添加机器人
3. 创建后复制 Webhook 地址

## 🚀 使用方法

### 基本用法

```bash
# 检查所有门店（导出+通知）
python main.py

# 检查指定门店
python main.py --store "阿狗手打·手作(长宁龙之梦店)"

# 仅导出不发送通知
python main.py --export-only

# 不发送通知
python main.py --no-notify
```

### 定时任务

```bash
# 启动定时任务（后台运行）
python main.py --schedule

# 使用nohup后台运行
nohup python main.py --schedule > monitor.log 2>&1 &
```

### 命令行参数

| 参数 | 简写 | 说明 |
|------|------|------|
| `--schedule` | `-s` | 启动定时任务模式 |
| `--export-only` | `-e` | 仅导出不发送通知 |
| `--no-notify` | `-n` | 不发送企业微信通知 |
| `--store` | - | 指定要检查的门店名称 |
| `--cookie` | - | 临时覆盖配置文件中的cookie |

## ⚠️ 注意事项

1. **Cookie有效期**: Cookie会过期，如果提示获取数据失败，请重新获取Cookie
2. **请求频率**: 工具已设置请求间隔，避免频率过高被限制
3. **定时任务**: 建议设置合理的检查间隔（默认30分钟）
4. **数据安全**: 请妥善保管Cookie，不要泄露给他人

## 🔧 常见问题

### Q: 提示"未获取到商品数据"？

A: 
1. 检查Cookie是否正确配置
2. Cookie可能已过期，需要重新获取
3. 检查shopId是否正确

### Q: 企业微信通知发送失败？

A: 
1. 检查Webhook地址是否正确
2. 确认机器人没有被禁用
3. 检查网络连接

### Q: 如何添加多个门店？

A: 在 `config.py` 的 `STORES` 列表中添加更多门店配置即可。
